# ExploreEase India Travel 🌴✈️

ExploreEase India Travel is a simple and responsive travel agency website designed to help users explore popular destinations and travel packages across India.

## 🌍 Features

- Home page with a travel hero section
- Popular Indian destinations
- Travel packages with prices
- Contact section
- Responsive design for mobile and desktop
- Navigation links for easy browsing

## 🏖️ Destinations

- Goa
- Jaipur, Rajasthan
- Kerala

## 📦 Travel Packages

- Goa Beach Escape
- Rajasthan Heritage Tour
- Kerala Backwater Holiday

## 🛠️ Technologies Used

- HTML5
- CSS3
